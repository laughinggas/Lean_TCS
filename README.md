# Welcome to the TCS Lean course!

## Installing Lean and Elan

Follow the instructions [here](https://lean-lang.org/install/)

Check that Elan and Lean are installed correctly by running:
```bash
lean --version
```

## Getting this repository on your laptop
Run the following command in your terminal:
```bash
git clone https://github.com/laughinggas/Lean_TCS
cd Lean_TCS
```

You may then verify that everything works by opening LeanTCS.lean. If the vertical orange bars disappear, and you see a Lean InfoView to the right side of the screen, all is good!

Alternatively, you may run the following code in your terminal:
```bash
lake build
```
You should get an output saying: Build completed successfully.

Happy Leaning!
